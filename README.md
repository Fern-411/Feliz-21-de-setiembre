# 🌻 Feliz 21 de Septiembre • Flores Amarillas
**Dedicatoria Especial e Interactiva para Ashley & Nedally ✨**

---

## 📌 Sobre esta Página Web

Página web desarrollada con **HTML5 Semántico, CSS3 de alta fidelidad visual y JavaScript Vanilla (ES6+)** para celebrar la tradición del **21 de Septiembre (Día de las Flores Amarillas)**.

Ofrece una experiencia inmersiva, emotiva y de alta calidad visual:
- **Vuelo Espacial de Entrada (Warp Cósmico):** Al presionar el botón de inicio, se emprende un viaje cinematográfico a través de un túnel oscuro donde flores amarillas y estrellas vuelan hacia la cámara con efecto de acercamiento hacia la galaxia.
- **Galaxia 3D Interactiva de Flores Amarillas:** Núcleo espiral con más de 14,000 partículas doradas, un corazón celestial tridimensional de polvo estelar y un gran ramo de girasoles central.
- **Rotación Libre en 3D (Mouse & Touch):** Puedes arrastrar con el cursor o el dedo en cualquier dirección para orbitar, inclinar y hacer zoom en la galaxia, con giro automático continuo y relajante.
- **Ramos y Flores Orbitando con Etiquetas Flotantes:** Múltiples ramos botánicos, ramilletes y girasoles en el plano orbital 3D con etiquetas luminosas (*"Luz de Ashley"*, *"Planeta Nedally"*, *"Amistad de Oro"*, *"Siempre Juntas"*, etc.).
- **Tarjetas de Dedicatoria Floral (Estilo Imagen de Referencia):** Al tocar cualquier flor o etiqueta, se despliega una tarjeta cálida vintage con ilustración botánica en la base y botón *`Cerrar 🌻`*.
- **100% Amistad Sincera (Cero Romance):** Mensajes respetuosos, nobles y profundos dedicados al compañerismo, la lealtad, las risas compartidas y el agradecimiento para Ashley y Nedally.
- **Música Sincronizada:** Canción clásica de *"Flores Amarillas"* con control de reproducción y ecualizador animado.
- **Lluvia de Pétalos y Chispas:** Sistema canvas de partículas que genera destellos al interactuar.

## 🚀 ¿Cómo ejecutar la página web?

1. Abre **Visual Studio Code**.
2. Abre la carpeta: `D:\UTP\VISUAL\Feliz 21`.
3. Abre la terminal (`Ctrl + ñ`) y ejecuta:
   ```bash
   node server.js
   ```
4. Se abrirá automáticamente en tu navegador en **`http://localhost:3001`**.

*(También puedes abrir directamente `index.html` con doble clic o con la extensión Live Server de VS Code).*
